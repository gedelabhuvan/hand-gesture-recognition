# AI-Based Hand Gesture Recognition

This project is developed using Google Teachable Machine, Python, OpenCV, and TensorFlow.

## Features
- Real-time hand gesture recognition
- AI image classification
- Webcam-based prediction

## Technologies Used
- Python
- TensorFlow
- OpenCV
- Teachable Machine

## How to Run

Install dependencies:

pip install tensorflow opencv-python numpy

Run the project:

py -3.10 main.py
